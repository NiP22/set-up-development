# Статусы triage

Для локальных задач выбраны стандартные пять ролей пакета скиллов.
В файле задачи роль хранится в строке `Status:`.

| Роль скилла | Значение Status | Смысл |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Требуется разбор обращения |
| `needs-info` | `needs-info` | Требуется информация от автора |
| `ready-for-agent` | `ready-for-agent` | Достаточно определено для работы агента |
| `ready-for-human` | `ready-for-human` | Требуется выполнение человеком |
| `wontfix` | `wontfix` | Принято решение не выполнять |

Эти роли описывают готовность и маршрутизацию задачи. Завершение подтверждается
её критериями и записанным результатом; для карт решений используется
отдельное поле, описанное в [issue-tracker.md](issue-tracker.md).
